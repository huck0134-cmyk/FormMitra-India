# FormMitra India

A beginner-friendly static website project for photo and document preparation tools.

## Files
- `index.html` — homepage and tool interface
- `style.css` — responsive styling and dark mode
- `script.js` — photo resize, image compression, image-to-PDF logic
- `privacy.html` — starter privacy policy

## Run locally
1. Extract this ZIP file.
2. Open the extracted `FormMitra_India` folder in VS Code.
3. Open `index.html` in your browser, or use VS Code Live Server.
4. Image-to-PDF needs internet access to load jsPDF from CDN.

## Current working tools
- Photo resize (width/height, aspect ratio)
- Image compression (quality; approximate target KB)
- Convert selected images to PDF
- Responsive layout and dark mode

Other cards are labelled “Coming soon” and are not implemented yet.

## Before publishing
- Replace the contact placeholder in `privacy.html`.
- Review all legal/privacy statements and make them accurate to your deployment.
- Test the site on mobile and desktop.
- Do not promise exact compressed file sizes: image format and content affect results.
- Consider adding a proper privacy policy, terms, disclaimer, contact page, sitemap, and SEO metadata.
- Do not add AdSense until the website has original useful content and complies with Google policies.

This is a static front-end project. It does not include a server, database, admin panel, or user-upload storage.
